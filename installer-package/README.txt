Pet Fresh Label Printer - Installation Package
============================================

This package contains everything needed to install Pet Fresh Label Printer.

INSTALLATION:
1. Right-click on "install.bat" and select "Run as administrator"
2. Follow the prompts to complete installation
3. The application will be installed to Program Files
4. Desktop and Start Menu shortcuts will be created

RUNNING THE APP:
- Use the desktop shortcut, or
- Use the Start Menu shortcut, or  
- Navigate to Program Files\Pet Fresh Label Printer\Pet Fresh Label Printer.exe

FEATURES:
- Full kiosk mode (no window controls)
- Settings accessible via gear icon
- Close app option in Settings > Application
- Emergency exit: Ctrl+Alt+Shift+X

For support, contact your system administrator.
